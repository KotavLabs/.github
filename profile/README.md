## Four focused ways to produce security evidence

<table>
  <tr><td><b>Website and application pentesting</b></td><td>Four fixed scopes, from a simple public website through authenticated applications, APIs, roles and business logic.</td></tr>
  <tr><td><b>Discovery Sprint</b></td><td>A structured, asynchronous diagnostic that maps one product, its security posture and its regulatory exposure.</td></tr>
  <tr><td><b>Argus Sentinel</b></td><td>Scheduled Argus assessments for one product, with human review reserved for material findings and two focused manual testing windows each year.</td></tr>
  <tr><td><b>Argus AppSec</b></td><td>Fast automated checks stay distinct from verified findings. Repository access authorises code analysis only; dynamic testing always requires a separate approved scope.</td></tr>
</table>
